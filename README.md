## 🌟 Overview

**AI JUGAAD CO 2.0** is a state-of-the-art cyber-futuristic web application and interactive **AI Website & Brand Designer Engine** inspired by [AI Jugaad Co](https://www.aijugaad.co/).

It transforms traditional web design agency portfolios into an immersive, high-tech digital experience featuring a dark glassmorphism matrix UI, interactive HTML5 particle canvas, synthesized Web Audio sound effects, real-time ROI calculator, live WhatsApp bot simulator, and an embedded interactive website wireframe generator.

---

## ✨ Key Features

### 1. 🌌 Cyber-Futuristic Visual System & Canvas Engine
- **Obsidian Dark Glassmorphism**: Neon Electric Cyan (`#00f0ff`), Quantum Purple (`#a855f7`), and Cyber Orange (`#ff5e00`) color palette.
- **Interactive 3D Node Matrix Canvas**: Mouse-attracted particle node backdrop with glowing vector connections reacting dynamically to user cursor movement.
- **Synthesized Web Audio SFX Engine**: Embedded audio synthesizer producing sci-fi UI clicks and hover sound effects (with toggleable mute button `[🔊 SFX: ACTIVE / MUTED]`).
- **Floating Interactive Stickers**: Retro-futuristic draggable stickers ("LOGOS", "WEBSITES", "AI BOTS").

### 2. 🚀 Interactive Live AI Website & Brand Designer Studio (`#ai-designer`)
- **Real-Time Wireframe Engine**: Visitors can select their industry (*E-Commerce Store, SaaS & Tech, Luxury Agency, Local Business*), choose a visual aesthetic vibe (*Cyberpunk Neon, Titanium Minimal, Obsidian Glass, Synthwave Glow*), input custom brand details, and toggle AI features.
- **Dynamic Live Viewport**: Real-time DOM canvas rendering wireframes with theme palette switching.
- **One-Click WhatsApp Blueprint Export**: Formats pre-filled project specifications and generates a direct link to dispatch specs to AI Jugaad's WhatsApp (+91 90808 92182).

### 3. 🤖 Autonomous AI WhatsApp Bot Live Simulator (`#bot-simulator`)
- Interactive phone chat widget where users can test drive real-time conversation flows with AI Jugaad's automated assistant (pricing estimates, logo package info, strategy call bookings).

### 4. 📊 Real-Time Business ROI & AI Savings Calculator (`#calculator`)
- Interactive sliders calculating monthly manual support hours saved, cost reduction in ₹, and estimated annual ROI multiplier in real-time.

### 5. 💼 Quantum Capabilities Matrix & Client Showcase (`#services`, `#work`)
- Deep breakdown of Logos, Neural Web Engineering, and WhatsApp AI Automation.
- Client showcase featuring *Deepsa India*, *Woody Tales*, *Velora Property Care*, and *Clay & Glaze*.

### 6. 👥 Leadership Hub & Command Terminal (`#team`, `#contact`)
- Profiles for founders **Simran Singh** (Founder & Product Architect) and **Sanket Agrawal** (Founder & AI Systems Lead).
- Interactive CLI-style command terminal for submitting project inquiries directly to WhatsApp.

## 🛠️ Technology Stack

- **Core Architecture**: HTML5, ES6+ Vanilla JavaScript
- **Styling & Design System**: Vanilla CSS3 (Custom HSL Tokens, Glassmorphism, Keyframe Animations, Grid & Flexbox Layouts)
- **Interactive Canvas Engine**: HTML5 2D Context Canvas API
- **Audio Engine**: Web Audio API (OscillatorNode & GainNode synthesizer)
- **Fonts**: Google Fonts (`Outfit`, `Space Grotesk`, `Inter`, `JetBrains Mono`)

## 🚀 Quick Start & Local Setup

No external node dependencies or build steps required. Simply run a local HTTP server:

```bash
# 1. Clone the repository
git clone https://github.com/albin669-gif/Website-design.git
cd Website-design

# 2. Start local HTTP server (Python 3)
python -m http.server 5500
```

Open your browser and navigate to:
**`http://localhost:5500`**
